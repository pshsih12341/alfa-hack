# Кредитный кабинет для малого бизнеса

[![Видео-демонстрация](https://img.youtube.com/vi/i3CTW6MuEII/maxresdefault.jpg)](https://youtu.be/i3CTW6MuEII)

**Сайт:** https://misisitmo.itatmisis.ru

Предприниматель подаёт заявку на кредит: сумма, срок, цель, ИНН. Всё остальное
сервис берёт сам по ИНН — реестры, БКИ, ФНС, обороты в Альфе. ML-модели за
несколько секунд оценивают риск и выдают решение: одобрение, предложение другой
суммы или срока, запрос выписок или отказ. Выписки — одна кнопка для клиентов
Альфы или файл 1С из другого банка. Сотрудник банка видит все заявки в своём
кабинете и отмечает выдачу.

## Запуск

```bash
docker compose up -d --build
docker compose exec backend python scripts/seed_admin.py +79990009999
```

Откройте http://localhost:8080. Вход по номеру телефона, без пароля.
Администратор — `+7 999 000-99-99`.

## Готовые аккаунты на сайте

Вкладка «Вход» → номер → «Открыть заявку». Действия необратимы: если статус уже
другой, заявку прошли до вас. Реквизиты — любые: БИК 9 цифр, счёт 20 цифр.

## Демо-ИНН

«Регистрация» → любой новый номер → ИНН, сумма и срок из таблицы → согласие
на запрос в БКИ. Цель и залог на тип решения не влияют.

| ИНН | Сумма и срок | Результат |
|---|---|---|
| `7476595370` | 2 450 000 ₽, 24 мес. | Одобрено, 18 %; с залогом — 17,5 % |
| `5483374635` | 4 100 000 ₽, 12 мес. | Предложение → «Пересмотреть по выпискам» → кнопка счёта → одобрено |
| `5991587272` | 1 050 000 ₽, 18 мес. | Нужны выписки → файл `5991587272.txt` → предложение |
| `2410358509` | 30 000 000 ₽, 24 мес. | Нужны выписки → `2410358509.txt` → одобрено; чужой файл отклоняется |
| `7819773951` | 1 000 000 ₽, 18 мес. | Нужны выписки → `7819773951.txt` → отказ |
| `524267417656` | 300 000 ₽, 12 мес. | Нужны выписки → кнопка счёта Альфы → одобрено |
| `669985868171` | любая | Отказ: перечень Росфинмониторинга |
| `636332069725` | 600 000 ₽, 12 мес. | Отказ по риску |

Файлы выписок — в [`mocks/statements/`](mocks/statements/).

## Все ИНН из базы

2000 синтетических компаний — таблица `egr_organizations` в
[`mocks/mocks.sqlite`](mocks/mocks.sqlite) (открывается в DB Browser for SQLite
или DBeaver) и в [`mocks/mocks_postgres.sql`](mocks/mocks_postgres.sql).
Из запущенного проекта:

```bash
docker compose exec postgres psql -U credit_kiosk -d mocks -P pager=off -c "select inn, name, status from egr_organizations order by name"
```
