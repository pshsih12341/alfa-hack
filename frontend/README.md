# Фронтенд — как запустить

Статический HTML-интерфейс. Собирать и запускать отдельно не нужно:
браузер делает запросы к тому же бэку.

## Где живёт файлы

- `backend/app/static/index.html` — главная страница и вся логика UI
- `backend/app/static/` — вложенные ресурсы

## Запуск

Один: бэк отдаёт фронтенд вместе с API:

```bash
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Открыть в браузере: http://localhost:8000/

## Примечание

Фронтенд НЕ выносится в `frontend/` — ограничение ТЗ: статику отдаёт
бэкенд. Если где-то в будущем понадобится отдельный UI-проект, перемещать
файлы `backend/app/static/` в `frontend/` и перенастраивать роутинг
исключительно на согласовании с backend-разработчиком.
